# TV 사이니지 시스템

태안 센터 TV 5대용 이미지 루핑 + 알람 방송 웹앱.

- 이미지/폰트/음원 파일 저장: **Cloudflare R2** (egress 무료 — 파일이 아무리 자주 로드돼도 트래픽 비용 없음)
- 스케줄/설정 데이터: **Supabase** (Postgres + Realtime)
- 앱 호스팅: **Vercel** (무료 티어) — 이미지 자체는 R2에서 직접 브라우저로 서빙되므로 Vercel 대역폭은 거의 쓰지 않음

## 1. Supabase 설정

1. https://supabase.com 에서 새 프로젝트 생성
2. 프로젝트 > SQL Editor 에서 `supabase/schema.sql` 내용을 그대로 실행
3. 프로젝트 > Settings > API 에서 다음 값을 복사해둠
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public` 키 → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role` 키 → `SUPABASE_SERVICE_ROLE_KEY` (절대 클라이언트에 노출되지 않도록 주의 — 서버 API 라우트에서만 사용됨)

## 2. Cloudflare R2 설정

1. Cloudflare 대시보드 > R2 > **Create bucket**, 이름 예: `tv-signage`
2. 버킷 > Settings > **Public access**를 켜고 r2.dev 개발용 URL을 활성화 (또는 직접 보유한 도메인을 연결). 이 URL이 `R2_PUBLIC_BASE_URL`
3. R2 > **Manage API tokens** > Create API token (버킷 읽기/쓰기 권한) → `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY` 발급
4. Cloudflare 계정 대시보드 우측에 있는 **Account ID**를 복사 → `R2_ACCOUNT_ID`
5. 버킷 > Settings > **CORS Policy**에 아래와 같이 추가 (배포될 Vercel 도메인을 실제 도메인으로 교체):

```json
[
  {
    "AllowedOrigins": ["https://your-app.vercel.app"],
    "AllowedMethods": ["PUT", "GET"],
    "AllowedHeaders": ["*"]
  }
]
```

이 CORS 설정이 없으면 관리자 페이지에서 이미지를 올릴 때 브라우저가 R2로의 직접 업로드(PUT)를 막습니다. 로컬 개발 중에는 `http://localhost:3000`도 같이 추가해두면 편합니다.

## 3. 로컬 환경변수

`.env.example`을 `.env.local`로 복사하고 위에서 발급한 값을 채워 넣습니다. `ADMIN_PASSWORD`는 관리자 페이지 접속용 비밀번호로 원하는 값을 직접 정하면 됩니다.

## 4. 설치 및 로컬 실행

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속 → 관리자 페이지(`/admin`)와 TV별 송출화면(`/player/1` ~ `/player/5`) 확인.

## 5. Vercel 배포

1. 이 프로젝트를 GitHub 저장소로 올림
2. https://vercel.com 에서 New Project → 해당 저장소 선택
3. Environment Variables에 `.env.local`의 모든 값을 동일하게 등록 (`NEXT_PUBLIC_...`, `SUPABASE_SERVICE_ROLE_KEY`, `R2_...`, `ADMIN_PASSWORD`)
4. Deploy
5. 배포된 도메인이 확정되면 2번의 R2 CORS `AllowedOrigins`를 실제 도메인으로 다시 저장

## 6. 각 TV에서 여는 방법

각 TV에 연결된 PC/셋톱박스의 브라우저에서 아래 주소를 **전체화면(F11 등 키오스크 모드)**으로 열어두면 됩니다.

```
https://your-app.vercel.app/player/1
https://your-app.vercel.app/player/2
https://your-app.vercel.app/player/3
https://your-app.vercel.app/player/4
https://your-app.vercel.app/player/5
```

브라우저 자동재생(오토플레이) 정책 때문에 알람 음원이 처음 한 번은 재생되지 않을 수 있습니다. 크롬을 `--autoplay-policy=no-user-gesture-required` 플래그로 실행하거나, 해당 사이트를 크롬 설정 > 사이트 설정 > 소리에서 "허용"으로 지정해두면 문제없이 자동재생됩니다.

## v9에서 추가된 것

- **엑셀 업로드 날짜/시간이 이상하게 들어가던 버그 수정**: 실제 날짜·시간 서식이 있는 엑셀(예: 별도로 만들어 쓰시는 스케줄 생성 도구의 출력물)을 업로드하면 시각이 몇 시간씩 틀리게 들어가는 문제가 있었습니다. 원인은 브라우저가 한국 시간대일 때 1899년(엑셀의 날짜 기준일) 시점의 옛 서울 지방시(LMT, 협정 이전 표준시)를 잘못 적용하는 자바스크립트의 알려진 함정 때문이었습니다. 날짜/시간 셀을 자바스크립트 Date 객체로 변환하지 않고 숫자 그대로 직접 계산하도록 고쳐서 이 문제를 없앴습니다.
- **플랜 관리(마스터 타임테이블 재사용)**: 프로그램·시작예정시각·렉처룸이 정리된 마스터 타임테이블 엑셀을 `/admin/day-plans`에서 한 번만 업로드해두면, 시트 하나하나가 이름 붙은 "플랜"으로 저장됩니다. 이후 알람 스케줄 탭에서 매번 엑셀을 올릴 필요 없이 **날짜 + 플랜만 선택**하면 그 플랜의 모든 프로그램이 그 날짜의 알람으로 한 번에 생성됩니다. 알람시각은 시작예정시각에서 지정한 분(기본 5분) 전으로 자동 계산됩니다.

## v8에서 추가된 것

- **빈도 그룹을 목록 어디에든 배치 가능**: 이전에는 빈도 그룹이 항상 재생목록 맨 끝에만 붙었는데, 이제는 "빈도 그룹 추가"로 만든 그룹이 재생목록 안에 하나의 항목(행)으로 들어가서, 이미지와 똑같이 드래그로 원하는 위치에 놓을 수 있습니다. 그룹 행의 "편집" 버튼을 누르면 그 자리에서 바로 그룹에 들어갈 이미지를 고르고 순서를 정할 수 있고, "완료"를 누르면 다시 한 줄로 접힙니다.
- 내부적으로 재생목록 저장 방식이 바뀌어서, 이번 업데이트는 마이그레이션이 필요합니다 (`migration_v7.sql`).

## v7에서 추가된 것

- **빈도 설정(재생목록·템플릿 공통)**: 재생목록이나 이미지 템플릿을 만들 때, 기본 이미지 목록 외에 "빈도 그룹"을 추가로 만들 수 있습니다. 한 그룹에 이미지를 여러 장 넣으면, 한 바퀴 돌 때마다 그 그룹에서 1장씩 번갈아가며 기본 목록 뒤에 붙습니다. 예: 기본 목록 1·2·3 + 빈도 그룹(4·5) → 1바퀴째 1,2,3,4 / 2바퀴째 1,2,3,5 / 3바퀴째 다시 1,2,3,4... 그룹은 여러 개 만들 수 있고, 템플릿에 들어있는 빈도 그룹은 TV에 템플릿을 적용할 때 TV의 빈도 그룹 목록 뒤에 그대로 추가됩니다.

## v6에서 추가된 것

- **관리자 화면 모바일 대응**: 좁은 화면(휴대폰)에서는 왼쪽 사이드바 대신 상단에 햄버거 메뉴(☰)가 뜨고, 눌러야 메뉴가 펼쳐집니다. 카드가 2열로 나란히 있던 화면(대시보드, 알람 서식 설정)은 1열로 쌓이고, 탭·버튼 줄은 화면 폭에 맞게 줄바꿈됩니다.

## v5에서 추가된 것

- **요일별 추가 이미지: 여러 요일 동시 선택**: "토요일+일요일 같은 시간에 같은 이미지"처럼, 한 번 등록할 때 여러 요일을 한꺼번에 고를 수 있습니다. 목록에도 실제 어떤 이미지가 걸려 있는지 썸네일로 보입니다.
- **이미지 전환 효과 제거**: 페이드/슬라이드가 제대로 동작하지 않아 완전히 없앴습니다. 대신 이미지 전환 시 잠깐 검은 화면이 보이던 원인(다음 이미지가 아직 로드되지 않은 채로 화면이 바뀌는 것)을 고쳤습니다 — 이제 재생목록의 모든 이미지를 미리 불러와두기 때문에 전환이 매끄럽게 바로 바뀝니다.
- **UI 더 촘촘하게, 썸네일 더 작게**: 카드 여백, 버튼 크기, 글자 크기를 전반적으로 줄이고, 이미지 그리드의 썸네일 크기를 줄여서 한 화면에 더 많은 이미지가 보이도록 했습니다. TV 설정 페이지의 "전환 속도/전환 효과"와 "알람 음원" 카드도 하나로 합쳤습니다.
- **요일별 이미지 화면 성능 개선**: 체크박스 그리드를 별도 컴포넌트로 분리해 불필요한 리렌더링을 줄이고, 작은 썸네일을 쓰도록 했습니다.

## v4에서 추가된 것

- **TV 이름 커스텀**: `/admin/tvs`에서 각 TV에 "1번 트랙 TV" 같은 실제 이름을 지어줄 수 있습니다. 관리자 화면 전체(탭, 바로가기 등)에 이 이름이 표시됩니다.
- **이미지 드래그앤드롭 업로드**: `/admin/images`에서 탐색기/파인더의 파일을 화면으로 바로 끌어다 놓아 업로드할 수 있습니다.
- **이미지 여러 장 업로드 시 버벅임 개선**: 업로드할 때 작은 미리보기(썸네일)를 자동으로 함께 만들어서, 관리자 화면의 이미지 그리드들은 원본 대신 이 작은 썸네일을 보여줍니다. TV 실제 송출 화면은 여전히 원본 화질 그대로 나갑니다. 기존에 이미 올려둔 이미지는 썸네일이 없어 원본으로 계속 보이니, 버벅임이 심하다면 다시 올려주시면 좋습니다.

## v3에서 추가된 것

- **동시 알람 2개씩 위아래 분할 로테이션**: 겹치는 알람이 3개 이상이면 2개씩 짝지어 위/아래로 분할해서 보여주고, 5초 간격으로 다음 2개 조합으로 넘어갑니다 (홀수로 남는 마지막 1개는 그 차례에 전체화면으로 표시).
- **알람 노출 시간을 TV별로 일괄 설정**: 더 이상 알람마다 따로 입력하지 않고, `/admin/alarms`에서 TV 탭마다 "노출 시간(초)" 하나만 정하면 그 TV의 모든 알람에 공통 적용됩니다.
- **알람이 날짜별로 묶여서 표시**: 같은 TV 안에서 날짜별 카드로 나뉘어 보이고, 날짜별로 한 번에 삭제하는 버튼도 있습니다. 엑셀에 여러 날짜를 한 시트에 이어 넣어도 업로드 후 자동으로 날짜별로 정리됩니다.
- **엑셀 날짜/시간 파싱 강화**: 외부 엑셀 툴에서 만든 파일도 인식하도록, 진짜 날짜 서식 셀, "YYYY-MM-DD" 텍스트, Excel 일련번호(예: 46277) 세 가지 형식을 모두 자동으로 처리합니다.
- **폰트 관리를 알람 서식 설정에 통합**: 별도 "폰트" 메뉴 없이 `/admin/settings`에서 업로드·선택·삭제까지 한 번에 하고, 오른쪽에 실시간 미리보기가 있어 줄별 글자 크기를 조절하면 바로 검은 화면 기준으로 어떻게 보이는지 확인할 수 있습니다.
- **이미지 전환 효과 선택**: `/admin/tvs`에서 즉시 전환/페이드/슬라이드 중 고를 수 있습니다.
- **재생목록을 클릭-추가 + 순서 리스트 방식으로 변경**: 이미지를 클릭할 때마다 목록 맨 뒤에 추가되고(같은 이미지 중복 추가 가능), 오른쪽/아래 "현재 재생 순서" 목록에서 각 항목의 "제외" 버튼으로 뺄 수 있습니다. 이미지 템플릿도 동일한 방식입니다.

## 이번 업데이트로 추가된 기능

- **이미지 템플릿**: `/admin/image-templates`에서 자주 쓰는 이미지 묶음을 이름 붙여 저장해두고, TV 설정 화면에서 "템플릿에서 추가" 드롭다운으로 한 번에 재생목록에 넣을 수 있습니다.
- **TV별 독립 알람**: 알람이 더 이상 여러 TV에 동시 배정되지 않고, TV 1~5 각각 완전히 별도의 알람 목록을 가집니다. `/admin/alarms`에서 TV 탭을 눌러 전환합니다.
- **엑셀 시트처럼 바로 수정**: 알람 목록이 표로 보이고, 칸을 클릭해 바로 수정하면 커서가 칸을 벗어나는 순간 자동 저장됩니다. 추가도 삭제도 표 안에서 바로 됩니다.
- **엑셀 업로드 컬럼 단순화**: 날짜 · 알람시각 · 시작예정시각 · 프로그램명 · 렉처룸, 5개 컬럼만 사용합니다. TV는 업로드할 때 선택된 탭으로 자동 지정되고, 글자 크기·폰트는 아래 "알람 서식 설정"에서 전체 공통으로 적용됩니다.
- **알람 문구 직접 수정**: `/admin/settings`에서 알람 화면에 뜨는 문구 자체([프로그램명], [장소], [시작시간] 자리표시자 포함)를 자유롭게 고칠 수 있고, 줄마다 글자 크기도 따로 지정할 수 있습니다.
- **관리자 화면에서 TV 화면 바로가기**: 왼쪽 메뉴 하단과 TV 설정/알람 화면 상단에 있는 "TV n ↗" 버튼을 누르면 새 탭에서 해당 TV의 실제 송출화면이 열립니다.
- **디자인 개선**: 전체적으로 카드/버튼/입력창 스타일을 다듬었습니다.

## 알아두어야 할 부분 (현재 구현의 가정/한계)

- **관리자 인증**: `/admin`은 Next.js 미들웨어 단의 간단한 공유 비밀번호 게이트입니다. 다만 관리자 화면은 Supabase **anon key**로 직접 DB에 쓰기 때문에, 배포된 사이트의 JS 번들에서 anon key를 추출하면 비밀번호 없이도 DB에 쓰는 것이 기술적으로 가능합니다. 신뢰할 수 있는 내부 직원만 접근한다는 전제라면 문제없지만, 더 엄격한 보안이 필요하면 쓰기 작업을 서버 API 라우트(`SUPABASE_SERVICE_ROLE_KEY` 사용)로 옮기고 RLS를 읽기 전용으로 잠그는 방향으로 바꿔야 합니다.
- **알람 음원**: TV별로 "이 TV는 알람 중 음원을 재생함" 여부와 파일 1개를 설정하는 구조입니다. 즉 그 TV에서는 어떤 알람이 뜨든 같은 음원이 재생됩니다. 알람마다 다른 음원을 쓰고 싶다면 `alarms` 테이블에 `audio_url` 컬럼을 추가하는 식으로 확장이 필요합니다.
- **엑셀 업로드 형식**: `/admin/alarms`에서 TV 탭을 먼저 선택한 뒤 "템플릿 다운로드"로 양식을 받아 채워서 업로드합니다. 컬럼: 날짜, 알람시각, 시작예정시각, 프로그램명, 렉처룸. 업로드된 알람은 전부 그 시점에 선택돼 있던 TV에만 등록됩니다.
- **알람시각 vs 시작예정시각**: "알람시각"은 검은 알람 화면이 실제로 뜨기 시작하는 시각이고, "시작예정시각"은 알람 문구 안 "시작 시간 : "에 표시되는, 실제 프로그램이 시작하는 시각입니다. 프로그램 시작 10분 전에 미리 알람을 띄우고 싶다면 알람시각을 시작예정시각보다 10분 이르게 넣으면 됩니다. 둘을 같게 넣으면 알람이 뜨는 순간이 곧 프로그램 시작 시간이 됩니다.
- **동시 알람 판단 기준**: 같은 TV의 알람들 중 현재 시각이 [알람시각, 알람시각+노출시간] 구간에 겹치는 것들을 "동시 알람"으로 봅니다. 노출시간은 TV별 공통 설정값입니다. 1개=전체화면, 2개 이상=2개씩 위/아래 분할, 5초 간격으로 다음 조합으로 로테이션(간격을 바꾸려면 `src/app/player/[tvId]/page.tsx`의 `ROTATE_EVERY_MS` 값을 조절하세요).
- **이미지 전환 방식**: 현재는 별도 전환 효과 없이 지정한 초 간격으로 바로 다음 이미지로 바뀝니다. 페이드 효과가 필요하면 추가 요청해주세요.
